# FocusFlow — SaaS лендинг + қолданба

Фрилансерлер мен командаларға арналған уақыт/тапсырма басқару өнімі:
конверсияға бағытталған лендинг **және** оның артындағы нақты жұмыс істейтін
қолданба — тіркелу, тапсырма басқару, таймер, апталық есеп.

**Стек:** React 19 (Vite) · Tailwind CSS v4 · React Router · lucide-react ·
Express 5 · SQLite (`node:sqlite`)

**Маршруттар:** `/` — лендинг · `/app` — қолданба · `/app/settings` —
параметрлер (соңғы екеуі тек кірген қолданушыға) · қалғаны — 404

## Лендингтегі мәліметтің бәрі шынайы

Бет артында нақты жұмыс істейтін өнім тұрғандықтан, ондағы бірде-бір мәлімет
ойдан шығарылмаған:

| Бұрын | Қазір |
|---|---|
| «12 000+ команда» | Тексеруге болатын фактілер (тегін, CSV, SQLite, 38 тест) |
| Ойдан шығарылған клиент логотиптері | Мүлдем алынып тасталды |
| Аты-жөні жазылған 3 адамның жалған пікірі | «Кімге арналған» сценарийлері — ешкімнің атынан кепілдік берілмейді |
| «14 күн тегін», «кез келген уақытта бас тарт» | Сынақ мерзімі де, жазылым да жоқ — сондай-ақ жазылды |
| Қолмен салынған «өнім скриншоты» | **Қолданбадан алынған нағыз экран суреті** |
| Жоқ мүмкіндіктер бар сияқты | Pricing-те **жоспарда** деп белгіленген |
| Ешқайда апармайтын 14 footer сілтемесі | Тек шынымен бар сілтемелер |

`public/app-dashboard.png` — қолмен салынған макет емес, жұмыс істеп тұрған
қолданбаның `/app` бетінен headless Chrome арқылы 2x сапада түсірілген нағыз
скриншоты (мысал аккаунттың деректерімен). UI өзгергенде оны қайта түсіру
керек — әйтпесе бет шындықтан ажырап қалады.

## Іске қосу

```bash
npm install
npm run dev      # фронт (5180) + API (3080) қатар қосылады
```

Аш: **http://localhost:5180**

Басқа командалар:

```bash
npm test         # 38 API тесті (node:test, уақытша SQLite-пен)
npm run dev:web  # тек Vite
npm run dev:api  # тек Express (node --watch)
npm run build    # dist/ шығады
npm start        # продакшн: Express дайын dist/-ті де, API-ды да береді (3080)
npm run lint
```

Ортаның айнымалылары (міндетті емес): `PORT` — API порты (әдепкі 3080),
`DB_FILE` — SQLite файлының жолы (әдепкі `server/data/focusflow.db`).

> **Порт туралы.** Әдепкі 5173-ті басқа жоба иеленіп қалса, Vite үнсіз басқа
> портқа көшеді де, 5173-те бөгде сайт ашылып тұрады. Шатаспау үшін
> [vite.config.js](vite.config.js)-те `strictPort` арқылы 5180 бекітілген —
> порт бос болмаса Vite енді жасырынып көшпей, қатемен тоқтайды. Ол `/api`
> сұраныстарын Express-ке проксилейді, сондықтан браузер үшін бәрі бір origin.

## Батырмалар не істейді

Бет статикалық емес — әр интерактив элемент нақты әрекет жасайды:

| Элемент | Әрекет |
|---|---|
| Get Started (Navbar / Hero / CTA) | тіркелу модалі → аккаунт құрылады → `/app` |
| Sign in | кіру модалі; кірген қолданушыға бірден `/app` |
| Watch Demo, Hero-дағы скриншот | 4 қадамдық демо турын ашады, өзі ойналады |
| Pricing тариф батырмалары | таңдалған тариф аккаунтқа жазылады |
| Ай / Жыл ауыстырғышы | бағаны және «үнемдейсің» есебін қайта санайды |
| Footer сілтемелері | нақты секцияға скролл, немесе toast ескертуі |

Модальдар: Escape-пен жабылады, backdrop-қа басқанда жабылады, Tab фокусы
ішінде қалады, жабылғанда фокус бұрынғы батырмаға қайтады, ашық тұрғанда бет
скроллы құлыпталады.

## Backend

Express 5 + SQLite. Деректер қоры — `node:sqlite` (Node 24-тің құрамында,
қосымша пакет қажет емес), файл: `server/data/focusflow.db` (git-ке кірмейді).

### API

| Метод | Жол | Не істейді |
|---|---|---|
| POST | `/api/auth/register` | аккаунт құрады, бастапқы жоба + 3 тапсырма береді |
| POST | `/api/auth/login` | кіру |
| POST | `/api/auth/logout` | сессияны жояды |
| GET | `/api/auth/me` | ағымдағы қолданушы |
| GET/POST/DELETE | `/api/projects` | жобалар |
| GET/POST/PATCH/DELETE | `/api/tasks` | тапсырма CRUD |

### Тестер

```bash
npm test
```

38 тест: тіркелу мен валидация, құпиясөздің хештелуі, сессияның мерзімі,
**қолданушылардың бір-бірінен оқшаулануы** (бөтен тапсырманы оқу/өзгерту/жою
және оған таймер қосу мүмкін емес), таймер инварианттары, есеп пен CSV
экрандауы, қауіпсіздік тақырыптары, rate limit. Әр тест файлы уақытша SQLite
файлымен жұмыс істейді — әзірлеушінің дерегіне тимейді.

### Қауіпсіздік

- Құпиясөз **scrypt**-пен хештеледі (кездейсоқ salt), салыстыру
  `timingSafeEqual` арқылы.
- Сессия — DB-де сақталатын кездейсоқ 32 байттық токен, **httpOnly** cookie
  ішінде (`sameSite=lax`, продакшнда `secure`). JWT-ден айырмашылығы — сессияны
  сервер жағынан бірден жоюға болады.
- Барлық сұраныс `user_id` бойынша сүзіледі — бөтен адамның тапсырмасын оқу да,
  өзгерту де мүмкін емес.
- `/api/auth/*` — минутына 10 әрекет (rate limit).
- Кіру қатесінде «email табылмады / құпиясөз қате» деп бөлмейміз — қай email
  тіркелгенін сыртқа шығармау үшін.
- «Бір мезгілде бір ғана таймер» шарты қосымша кодта емес, SQLite-тың
  partial unique index-і арқылы бекітілген.
- Қауіпсіздік тақырыптары: CSP, `X-Frame-Options`, `nosniff`, HSTS
  (продакшнда), `X-Powered-By` өшірілген.
- Құпиясөз ауысқанда барлық сессия жойылады — ұрланған сессия жарамсыз болады.

### Тұрақтылық

- SIGTERM/SIGINT келгенде жүріп жатқан сұраныстар аяқталып, SQLite дұрыс
  жабылады (10 секундтан кейін мәжбүрлеп) — WAL файлы бүлінбейді.
- Дұрыс емес JSON 400, тым үлкен body 413 қайтарады, 500 емес.
- Frontend-те `ErrorBoundary` бар: рендер қатесі ақ экранға айналдырмайды.
- Бет фоннан оралғанда таймер серверден нақтыланады (дрейфке қарсы).

## Дизайн жүйесі

Барлық токен [src/index.css](src/index.css) ішіндегі `@theme` блогында.

- **Primary:** `brand-600` (indigo-600). Түсті тек `brand-*` және `slate-*`
  палитрасынан ал — жаңа түс қоспа.
- **Секция аралығы:** `py-24 sm:py-32`, контейнер `mx-auto max-w-7xl px-6 lg:px-8`.
- **Қаріп иерархиясы:** h1 `text-5xl sm:text-6xl lg:text-7xl`, h2 `text-4xl sm:text-5xl`,
  body `text-base`/`text-lg`.
- **Радиус:** батырмалар `rounded-full`, карталар `rounded-2xl`/`rounded-3xl`.

Primary түсті ауыстыру үшін `index.css`-тегі `--color-brand-*` мәндерін
Tailwind палитрасының басқа түсімен алмастыр — бүкіл бет соңынан өзгереді.

## Деплой

> **Маңызды:** backend қосылғаннан кейін таза Vercel деплойы жеткіліксіз.
> Vercel-дің serverless функцияларының файл жүйесі уақытша — SQLite файлы әр
> «суық іске қосылуда» жоғалады, әрі процесс тұрақты жұмыс істемейді.
> Сондықтан **тұрақты дискі бар** хостинг керек.

**1-нұсқа (ұсынылады) — бәрін бір жерде:** Render / Railway / Fly.io.
Express продакшнда `dist/`-ті де өзі беретіндіктен, бір ғана сервис жеткілікті:

```bash
# Build Command
npm install && npm run build
# Start Command
npm start
```

Persistent disk қосып, `DB_FILE`-ды соған бағыттау керек, әйтпесе деплой сайын
дерек жоғалады:

```
DB_FILE=/data/focusflow.db
NODE_ENV=production
```

**2-нұсқа — бөліп деплой ету:** фронт Vercel-де, API Render-де қалады. Ол
жағдайда cookie басқа доменнен жүруі үшін `sameSite: 'none'` + `secure: true`
керек болады ([server/auth.js](server/auth.js)) және Express-ке CORS қосу
қажет. Бірінші нұсқасы қарапайымырақ.

**SQLite-тан Postgres-ке көшу.** Барлық SQL сұраныс `server/routes/*` ішінде
жинақталған — ДҚ-ны ауыстырғанда тек `server/db.js` мен сол сұраныстар
өзгереді, фронт мүлдем тиылмайды.

```bash
git init && git add . && git commit -m "FocusFlow: landing + app"
```
